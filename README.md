# High‑Security Flask-PWA-Repo-Template

This repository is the official detnsw-sydtech high‑security Flask Progressive Web App template for SE12 Software Engineering students.

It provides:
- A modern Python toolchain using \`pyproject.toml\` and \`uv\`
- A secure-by-default Flask architecture with blueprints and layered security
- A PWA structure including manifest, service worker, and offline support
- A CI pipeline including linting, testing, and Wapiti dynamic security scanning
- A clean, extensible project layout suitable for Major Projects

Full documentation will be added as the project is built out.
